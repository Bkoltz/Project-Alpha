USER WORKFLOWS
───────────────────────────────────────────────────────────────────────────────

ENABLE AUTO-EMAILS:
  1. Go to /?page=settings → Invoices tab
  2. Check: "Send reminder when invoice is due in 7 days"
  3. Check: "Send weekly reminder for overdue invoices"
  4. Click "Save"
  5. ✅ Auto-emails configured!

VIEW SENT REMINDERS:
  1. Go to /?page=invoice/notifications-list
  2. View all sent reminders with filters
  3. Filter by type/date/invoice ID
  4. See complete audit trail
  5. ✅ Full visibility into sends!

ADD EXTRA CHARGES:
  1. Edit an invoice
  2. Scroll to "Extra Charges (editable)" section
  3. Click "+ Add Extra Charge"
  4. Enter description, qty, price
  5. Save invoice
  6. View PDF — yellow badge shows extra charges
  7. ✅ Flexible billing!

CONFIGURATION REQUIRED
───────────────────────────────────────────────────────────────────────────────

Settings (Settings UI):
  invoice_auto_send_due_7days        = 1 (enable/disable)
  invoice_auto_send_overdue_weekly   = 1 (enable/disable)
  documents_valid_days               = 7 (reminder link expiry)

SMTP (must already be configured):
  smtp_host              = smtp.gmail.com (or your provider)
  smtp_port              = 587
  smtp_username          = your-email@company.com
  smtp_password_enc      = (encrypted via crypto_encrypt)
  smtp_secure_tls        = 1
  from_email             = noreply@company.com
  from_name              = Company Name

Cron Schedule (choose one):
  Option A (Separate cron):
    0 9 * * * /usr/bin/php /var/www/src/cron/send_invoice_reminders.php

  Option B (Embedded in main cron):
    0 10 * * * /usr/bin/php /var/www/src/cron/generate_recurring_invoices.php
