# Projects and Jobs

Projects give PA a central place for work that spans more than one document or client contact.

## What a Project Can Hold

- Primary client or organization
- Additional clients
- Department context
- Quotes, contracts, invoices, and project invoices
- Files and external links
- Project notes and status
- Public project access settings

## Public Project Links

Project links are long-term public links. They can be view-only or allow limited actions such as uploads, depending on ACL settings. A project link can also be protected by a single password set in project settings.

## Organizations and Departments

If an organization has no departments, PA can use the overall organization folder. When departments exist, PA switches to department-specific linking so records stay in the right place.

## When to Use Projects

Use a project when work has multiple documents, shared files, multiple contacts, or a job code that should stay visible across the workflow.
