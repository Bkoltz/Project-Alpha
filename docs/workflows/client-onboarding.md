# Client Onboarding

Client onboarding lets a client submit or update their own contact details through a public link.

## How It Works

1. A PA user creates an onboarding invitation.
2. The client opens the link.
3. The client submits name, email, phone, address, and client type.
4. PA flags possible matches.
5. A PA user reviews the submission.
6. The reviewer creates a new client, keeps the existing one, or merges selected fields.

## Individuals and Organizations

The public form defaults to **Individual**. If the client selects **Organization**, PA shows an organization textbox so they can type the organization name. During review, the PA user can match that typed organization to an existing organization or create a new one.

## Notifications

Onboarding links can notify admins when a new submission arrives. The setting is also available under notification settings so it stays clear and synchronized.
